# COVID-19 & CPI Inflation Analysis — Excel

## Project Overview
Analyzed Consumer Price Index (CPI) data using Microsoft Excel
to explore inflation trends across Rural, Urban, and Combined
categories.

## Objectives
- Analyze Rural, Urban, and Combined CPI trends.
- Calculate Month-on-Month (MoM) inflation.
- Analyze Year-on-Year (YoY) inflation.
- Compare category-wise inflation trends.
- Explore the relationship between imported crude oil prices
  and Transport & Communication inflation.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts and Data Visualization
- Statistical Analysis

## Key Analysis
- Compared monthly and annual inflation trends.
- Identified categories contributing to inflation.
- Examined the relationship between crude oil prices and
  Transport & Communication inflation during 2021–2023.
- Observed a correlation of approximately 0.67 between the
  two variables.
